# Frontend (Portfolio Dashboard)

This is a Vite + React TypeScript frontend for the Multi-Account Portfolio project.

Quick start

```bash
cd Frontend
npm install
npm run dev
```

Notes
- The UI expects the backend at `http://localhost:4000` by default. Set `VITE_API_BASE` to change it.
- Save an `accessToken` to `localStorage` under `accessToken` (or implement login) before calling protected endpoints.
